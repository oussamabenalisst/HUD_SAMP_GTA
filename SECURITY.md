# Security Policy

## Supported Versions

This project is a community modification for Grand Theft Auto: San Andreas and SA-MP. Security fixes are considered for the current version available on the `main` branch.

| Version        | Supported    |
| -------------- | ------------ |
| `main`         | Yes          |
| Older releases | No guarantee |

## Reporting a Vulnerability

Please do not disclose suspected security vulnerabilities in a public issue, pull request, or discussion.

Report vulnerabilities privately through the repository's **Security** tab using **Report a vulnerability**, if GitHub private vulnerability reporting is enabled. If that option is unavailable, contact the project maintainer privately through the contact information associated with the repository.

Include the following details when possible:

- A clear description of the vulnerability.
- The affected file, component, or version.
- Steps to reproduce the issue.
- The potential impact.
- Any suggested mitigation or fix.

Please allow the maintainers reasonable time to investigate and prepare a fix before publicly sharing the issue.

## Scope

Security reports may include vulnerabilities in the project files, scripts, plugins, configuration, or installation process. Do not send passwords, private keys, personal data, or other sensitive information that is not required to reproduce the issue.

## Response

The maintainers will review valid reports, request additional information when needed, and determine the appropriate remediation. Public disclosure and release timing will be coordinated when practical.
