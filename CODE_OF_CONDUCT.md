# Code of Conduct

## Our Commitment

We are committed to making participation in this project a respectful, welcoming, and harassment-free experience for everyone, regardless of background, identity, experience level, or viewpoint.

## Expected Behavior

Participants are expected to:

- Be respectful and considerate in discussions and code reviews.
- Use inclusive and professional language.
- Give and receive constructive feedback in good faith.
- Focus on the project and its technical goals.
- Respect different opinions and levels of experience.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment, discrimination, threats, or personal attacks.
- Trolling, insulting, or deliberately disruptive comments.
- Publishing private information without permission.
- Sexualized language or unwanted attention.
- Any conduct that would be inappropriate in a professional community.

## Reporting Problems

If you experience or witness unacceptable behavior, report it privately to the project maintainer through the repository's available private contact or security-reporting channel. Please include enough information to help investigate the incident. Reports will be handled as confidentially as possible.

## Enforcement

Project maintainers may remove comments, reject contributions, restrict participation, or take other appropriate action when this Code of Conduct is violated.

This Code of Conduct applies to all project spaces, including issues, pull requests, discussions, and other project-related communication.
